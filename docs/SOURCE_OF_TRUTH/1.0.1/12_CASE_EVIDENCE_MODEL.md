## Separación

**PRODUCT** = el sistema. **CASE** = su aplicación real.

Ejemplos: DataSucumbíos / PDOT Sucumbíos. SIGDR / Dayuma–Inés Arango.

CaseDetail futuro (no programar): context, problem, methodology, products/components, fieldwork, phases, evidence, photography, documents, results_confirmed, limitations. No forzar todas las fases.

Fotos históricas: **evidencia narrativa**, no decoración. Estructura Wix valiosa: proyecto → fase → informe → fotografía. Preservar conceptualmente. **No copiar assets Wix automáticamente.**

Pipeline media: DISCOVERED → NEEDS_REVIEW → APPROVED → PUBLICABLE.

Campos foto: project/case, phase, year, location, caption, credit, authorizationStatus.
