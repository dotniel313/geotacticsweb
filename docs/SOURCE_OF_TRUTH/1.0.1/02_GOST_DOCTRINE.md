## 1. Principio central (decisión doctrinal)

GeoTactics **no comienza por una tecnología**. Comienza por un **problema real**. Analiza, según corresponda: actores; territorio; información; procesos; relaciones; eventos; operación; objetivos de gestión. Luego estructura el sistema y selecciona disciplinas, arquitecturas y tecnologías.

**Hipótesis narrativa corporativa (interna; no slogan de campaña hasta aprobación de copy):**

> GeoTactics diseña sistemas de información alrededor de problemas reales.

La diversidad de productos no implica ausencia de identidad. El dominio cambia. La materialización cambia. La forma de estructurar el problema mantiene continuidad.

## 2. Confirmación del propietario

**CONFIRMED_OWNER — 18 septiembre 2026**

Todos los desarrollos posteriores de GeoTactics utilizan GOST de manera ontológica.

**G.O.S.T.** — Gestión Operativa de Sistemas Territoriales.

GOST es fundamento ontológico, marco conceptual y metodología GeoTactics. **No** es simplemente software. **No** compite con BI, GIS, DW, Data Mart, OLAP, CMI, bases de datos, móviles ni web.

Que un producto tenga fundamento ontológico GOST **no** implica ciclo completo, BI, GIS, DW, Mart, OLAP, CMI, misma arquitectura, código compartido ni inteligencia territorial.
