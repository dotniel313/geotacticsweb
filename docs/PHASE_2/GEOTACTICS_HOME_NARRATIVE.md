### 05 GOST / CÓMO TRABAJAMOS

Título: Cómo convertimos información territorial en decisión.

**Capa pública (4 pasos):**

```
CAPTURAR → CONECTAR → ENTENDER → DECIDIR
```

**Mapeo interno (no omitir significado; puede ir en tooltip / `/tecnologia`):**

| Capa pública | Ciclo GOST real |
|---|---|
| CAPTURAR | Captura |
| CONECTAR | Organización / integración + territorio / georreferenciación |
| ENTENDER | Sistematización + analítica + indicadores |
| DECIDIR | Gestión + decisión |

BI/DW/Mart/GIS/OLAP: una línea — “capas de explotación dentro del ciclo, no una metodología rival”.

**No afirmar:** patente, ISO, novedad mundial, predicción demostrada, ahorro fiscal, “GOST desde 2008” como hecho documental, MadaRadio = GOST-software.

Enlace: `/tecnologia`.
